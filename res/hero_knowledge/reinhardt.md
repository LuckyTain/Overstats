# 核心定位
莱因哈特通过屏障力场保护团队、火箭重锤近战输出、冲锋位移控制与裂地猛击完成团控。
评价时不能只看伤害或击杀，还需要结合生存、护盾使用效率、空间创造以及团队整体推进/防守效果。

# 重点评价维度
## 生存与资源管理
优先参考：death, damageTaken, healingTaken, 使用时间
解释规则：主坦死亡对团队影响巨大，死亡控制是核心指标。高承伤但低死亡通常意味着有效吸收。

## 输出与控制贡献
优先参考：heroDamage, kill, assist, finalHit
解释规则：坦克伤害不应与输出职责直接比较。助攻与击杀参与反映冲锋与大招贡献。

## 功能性
可用证据：assist/kill、本局威能
限制：无护盾或技能具体数据时，不得断言护盾使用时机错误或大招空大。

# 数据解释注意事项
- 不要仅凭低伤害判定未完成职责。
- 使用时间短时不作强结论。

# 建议生成规则
当死亡明显偏高时：建议检查护盾使用时机与冲锋是否过度深入。
当承伤高但死亡可控、助攻较好时：可评价为有效吸收与空间创造。

# 不可推断事项
- 护盾挡了多少具体伤害或技能
- 冲锋钉死了某个目标
- 裂地猛击命中了多少人
- 具体站位细节

# 技能摘要
火箭重锤、屏障力场、冲锋、烈焰打击、裂地猛击

# 威能
点评时结合本局实际选择。
