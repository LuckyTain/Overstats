# 核心定位
猎空通过闪烁与回溯实现极高机动，使用脉冲手枪进行近距离持续输出，并以脉冲炸弹完成收割。
评价时不能只看伤害总量，还需要结合生存、击杀参与、最终击杀以及是否有效消耗敌方关键目标。

# 重点评价维度
## 生存
优先参考：death, damageTaken, healingTaken, 使用时间
解释规则：生命值低，依赖闪烁与回溯保命，死亡控制是核心指标。

## 输出与目标选择
优先参考：heroDamage, kill, finalHit, assist
解释规则：最终击杀比例较高通常意味着收割能力强。

## 功能性
可用证据：assist/kill/finalHit、本局威能
限制：无位置或技能具体命中数据时，不得断言闪烁路径或炸弹浪费。

# 数据解释注意事项
- 不要将伤害与远程持续输出直接比较。
- 使用时间短时不作强结论。

# 建议生成规则
当死亡明显偏高时：建议检查闪烁/回溯时机与是否过度深入。
当击杀与最终击杀突出且死亡可控时：可评价为侧翼与收割效率较高。

# 不可推断事项
- 具体闪烁路径或回溯位置
- 脉冲炸弹粘附了某个目标
- 具体站位细节
- 语音沟通情况

# 技能摘要
脉冲手枪、闪烁、回溯、脉冲炸弹

# 威能
点评时结合本局实际选择。
