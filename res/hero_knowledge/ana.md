# 核心定位

安娜通过远程治疗、睡眠针、生化手雷和纳米激素影响战局。

评价安娜时不能只看治疗总量，还需要结合生存、输出、击杀参与和死亡情况。

# 重点评价维度

## 生存

优先参考：
- `death`
- `damageTaken`
- `healingTaken`
- 英雄使用时间

解释规则：
- 安娜缺少常规位移，死亡控制是重要评价指标。
- 高治疗量不能完全抵消频繁死亡。
- `damageTaken` 较高但死亡较低，可以视为具有一定生存和资源转换能力。
- 不能只根据 `damageTaken` 判断站位错误。

## 治疗与资源分配

优先参考：
- `cure`
- `heroDamage`
- `kill`
- `assist`
- `finalHit`

解释规则：
- 治疗量不是越高越好，需要同时判断是否贡献输出和击杀参与。
- 伤害偏低不一定是问题。
- 治疗较低但伤害、击杀和助攻表现突出时，可能属于主动进攻型打法。
- 只有治疗、没有输出或击杀参与，不能自动判定为优秀。

## 控制和功能性

可用证据：
- `assist`
- `kill`
- `finalHit`
- 本局选择的威能
- 后端提供的英雄专属统计

限制：
- 如果比赛数据没有睡眠针命中、禁疗命中或纳米激素收益，不得编造这些事件。
- 可以指出这些是复盘重点，但不能断言玩家使用失败。

# 数据解释注意事项

- 不要将安娜的伤害直接与输出职责比较。
- 不要仅凭治疗量判定安娜是否完成职责。
- 不要把低助攻机械解释为缺少团队配合。
- 如果缺少技能命中数据，应明确写成“建议复盘”，而不是既定结论。
- 如果安娜使用时间很短，不对其表现作独立强结论。

# 建议生成规则

当死亡明显偏高时：
- 建议检查站位、视野暴露、撤退时机以及睡眠针是否过早消耗。
- 不得在没有位置数据的情况下直接断言“站位靠前”。

当治疗很高但输出和击杀参与偏低时：
- 建议检查是否过度专注治疗，错过对残血目标补枪和对敌方前排施压的机会。

当治疗低但输出、击杀和助攻较好时：
- 不要机械批评治疗不足。
- 需要结合队伍胜负、同职责表现和死亡数判断资源分配是否有效。

当死亡低且治疗、输出、助攻均衡时：
- 可以评价为资源分配和生存较好。
- 如果缺少技能数据，不要额外夸大睡眠针或生化手雷表现。

# 不可推断事项

以下结论没有对应数据时禁止生成：
- 睡眠针命中了某个关键目标
- 生化手雷命中了多少敌人
- 纳米激素给错了目标
- 玩家站位具体位于前排或后排
- 玩家是否与队友进行了语音沟通
- 某次死亡是否因为队友没有保护

# 技能摘要（理解用）

- 生物步枪：远程治疗/伤害
- 睡眠针：关键控制
- 生化手雷：范围治疗 + 禁疗
- 纳米激素：指定友军强化

# 威能

点评时结合本局实际选择的威能调整评价标准。若缺少威能数据，保持通用评价。
