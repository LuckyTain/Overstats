# 核心定位
源氏通过手里剑、弹反、疾影与龙刃完成高机动收割。
评价时不能只看伤害总量，还需要结合生存、最终击杀、击杀参与以及是否有效针对后排。

# 重点评价维度
## 生存
优先参考：death, damageTaken, healingTaken, 使用时间
解释规则：依赖弹反与机动保命，死亡控制重要。

## 输出与收割
优先参考：heroDamage, kill, finalHit, assist
解释规则：最终击杀比例与龙刃相关击杀是评价收割能力的关键。

## 功能性
可用证据：assist/kill/finalHit、本局威能
限制：无弹反具体数据时，不得断言弹反成功/失败次数。

# 数据解释注意事项
- 不要将伤害与持续远程输出直接比较。
- 使用时间短时不作强结论。

# 建议生成规则
当死亡明显偏高时：建议检查弹反时机与疾影使用是否过于激进。
当击杀与最终击杀突出且死亡可控时：可评价为刺客效率较高。

# 不可推断事项
- 弹反了某个具体技能
- 疾影击杀重置次数
- 龙刃期间具体击杀过程
- 具体站位

# 技能摘要
手里剑、疾影、弹反、龙刃

# 威能
点评时结合本局实际选择。
