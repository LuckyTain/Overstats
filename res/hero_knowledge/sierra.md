# 核心定位

西拉 的玩法定位围绕其职责与技能组展开。评价时不能只看单一指标（治疗/伤害/击杀），需结合生存、参战、资源分配与死亡控制综合判断。

# 重点评价维度

## 生存
优先参考：death、damageTaken、healingTaken、英雄使用时间
解释规则：死亡控制是重要评价指标。高输出/治疗不能完全抵消频繁死亡。

## 输出 / 治疗 / 资源分配
优先参考：cure（支援）、heroDamage、kill、assist、finalHit
解释规则：需结合职责判断资源分配是否有效。低治疗高参战或低伤害高最终击杀都可能属于有效打法。

## 控制与功能性
可用证据：assist、kill、finalHit、本局威能、专属统计（若有）
限制：无技能命中或具体位置数据时，不得编造相关结论。

# 数据解释注意事项
- 不要仅凭单一数值判定职责完成度。
- 使用时间很短时不作独立强结论。
- 缺少技能数据时写成“建议复盘”。

# 建议生成规则
当死亡明显偏高时：建议检查站位、技能使用时机与是否被针对。不得在没有位置数据时直接断言站位错误。
当关键数据（治疗/伤害/击杀）表现突出且死亡可控时：可给予正面评价。
当数据矛盾时：结合队伍胜负与同职责表现判断。

# 不可推断事项
- 具体技能命中某个目标
- 玩家站位具体位于前排或后排
- 玩家是否与队友语音沟通
- 某次死亡归因于队友未保护

# 威能
点评时结合本局实际选择的威能调整评价标准。若缺少威能数据，保持通用评价。
