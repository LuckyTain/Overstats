# 核心定位

D.Mon 是 MEKA 小队新任领队，驾驶机甲「野兽」（Beast），以等离子剑近战输出 + 强力屏障防守为主，兼具水平助推机动与临时远程火力。机甲被摧毁后可弹射为飞行员形态，再用终极技能呼叫机甲重组。

评价时不能只看伤害或击杀，需结合生存（机甲存活时间与弹射后表现）、屏障使用效率、突进与空间压制、以及最终击杀/助攻贡献。她更接近「带机动的剑盾主坦」，而非 D.Va 式俯冲侧翼。

# 重点评价维度

## 生存

优先参考：
- `death`
- `damageTaken`
- `healingTaken`
- 英雄使用时间
- 机甲被摧毁次数 / 飞行员形态存活时间（若有专属统计）

解释规则：
- 机甲提供高护甲与第二生命，死亡控制仍是核心指标。
- 高承伤但低死亡，通常意味着有效吸收与屏障管理。
- 弹射后飞行员形态脆弱，频繁弹射后立刻阵亡需重点复盘。
- 不能仅凭高 `damageTaken` 判定站位错误。

## 输出与控制贡献

优先参考：
- `heroDamage`
- `kill`
- `assist`
- `finalHit`

解释规则：
- 近战伤害为主，不应与远程输出职责直接比较。
- 突进刺击、无极斩的命中与转化是关键观察点。
- 助攻与最终击杀反映屏障掩护下的团队推进价值。

## 功能性（屏障与空间）

可用证据：
- `assist` / `kill`
- 本局选择的威能
- 若有屏障承受伤害、助推使用、突进刺击命中等专属统计

限制：
- 无屏障或技能具体数据时，不得断言「屏障开错时机」或「突进空了」。
- 可以指出屏障与突进是复盘重点。

# 数据解释注意事项

- 不要将 D.Mon 的伤害与输出英雄直接比较。
- 不要仅凭低伤害判定未完成职责（可能以屏障与空间创造为主）。
- 使用时间很短时不作独立强结论。
- 缺少技能命中数据时，写成「建议复盘」，而非既定结论。
- 飞行员形态与机甲形态的数据需分开理解（若后端能区分）。

# 建议生成规则

当死亡明显偏高时：
- 建议检查屏障持续时间、助推消耗时机、突进后是否过度深入，以及弹射后的生存处理。
- 不得在没有位置数据的情况下直接断言「站位靠前」。

当承伤高但死亡可控、助攻较好时：
- 可评价为有效吸收与空间创造。

当伤害/最终击杀偏低但团队推进顺利时：
- 不要机械批评输出不足，需结合同职责表现与胜负判断。

当机甲频繁被破且弹射后表现差时：
- 建议检查屏障管理与呼叫机甲时机。

# 不可推断事项

以下结论没有对应数据时禁止生成：
- 强力屏障挡了多少具体伤害或技能
- 突进刺击命中了某个关键目标
- 无极斩具体命中人数与增伤收益
- 玩家站位具体位于前排或后排
- 玩家是否与队友进行了语音沟通
- 某次死亡是否因为队友没有保护
- 机甲弹射的具体原因细节

# 技能摘要（理解用）

**被动**
- 职责：重装（终极充能减免、预设职责额外生命）
- 副职责：铁壁（+40% 击退/减速抗性）
- 弹射！：机甲被摧毁时弹出，短暂无敌

**武器**
- 等离子剑（机甲主武器）：近战，伤害 65，范围约 4 米
- 手提聚变连发枪（飞行员）：重机枪，可暴击

**技能**
- 强力屏障（副攻击）：前方能量屏障，生命值 650，持盾移速 -30%，被毁后 5 秒冷却
- 助推器（技能1）：消耗燃料水平突进，可造成少量伤害与击退
- 聚变连发枪（技能2）：临时激活速射机枪（约 4 秒）
- 突进刺击（持盾时主攻击）：向前疾冲，伤害并击退敌人

**终极技能**
- 无极斩（机甲）：横扫斩击，自身获得过量生命，并使命中敌人承受伤害提高
- 呼叫机甲（飞行员）：重组机甲，范围伤害与击退

# 威能（Perks）

## 次级威能（Level 2 选择其一）

### 野兽之心
机制摘要：
- 等离子剑命中会为强力屏障恢复 40 点生命值。
点评影响：
- 鼓励近战交战与屏障续航，可更关注近身输出与屏障存活时间。

### MEKA机动
机制摘要：
- 按住强力屏障时，助推器燃料消耗降低 30%。
点评影响：
- 持盾机动性提升，可更关注边盾边推的推进效率。

## 主要威能（Level 3 选择其一）

### 强突刺击
机制摘要：
- 突进刺击获得 150% 生命汲取。
点评影响：
- 突进生存与持续交战能力增强，可更重视突进后的存活与击杀转化。

### 聚焦聚变
机制摘要：
- 聚变连发枪发射无散布的强效射击，但射速降低。
点评影响：
- 远程压制精度提升，评价时可更关注技能2期间的输出贡献。
